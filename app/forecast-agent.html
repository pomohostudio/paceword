Forecast Agent

Ask about any future event. You get a probability, a 90% interval, and the reasoning — outside view first, increments in log-odds, cruxes named. Every forecast is logged and can be scored when it resolves. In-page forecasts reason from model knowledge plus whatever evidence you paste — there is no live web here; for retrieval-grade work use the forecast-agent in Claude Code.

Working

Ledger

Click a question to reopen its full reasoning. YES/NO = how reality resolved per the entry's named criterion; that click computes the Brier score. Mark outcomes when reality arrives — the Brier score against your logged probability is the only evidence this agent works. Baseline to beat: 0.25 (always saying 50%).

Method: FORECASTING.md · seven audited failure modes checked by name · no self-extremizing · intervals mandatory.
